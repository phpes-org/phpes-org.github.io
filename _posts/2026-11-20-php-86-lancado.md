O PHP 8.6 foi lançado em 19 de novembro de 2026. Não é uma versão tão grande quanto o PHP 8.0 ou 8.1, mas traz várias novidades úteis no dia a dia.

Principais novidades:

- **Partial Function Application**: chamar uma função com `?` no lugar de alguns argumentos retorna uma closure que recebe o restante.
- **Classe `\Time\Duration`**: representa um intervalo de tempo com precisão de nanossegundos, independente de fuso horário.
- **Função `clamp()`**: mantém um valor dentro de um intervalo.
- **Enum `SortDirection`**: substitui constantes inteiras para indicar a direção de ordenação.
- **Valores padrão em propriedades readonly**.
- **Polling API (`Io\Poll`)**: monitora vários streams ao mesmo tempo usando epoll, kqueue, event ports ou WSAPoll, conforme a plataforma.
- **Tratamento de erros em streams** com exceções.
- **DocComments em parâmetros** de funções e métodos, acessíveis via `ReflectionParameter::getDocComment()`.

### Partial Function Application

```php
$versions = ['8.4', '8.5', '8.6', '8.7', '9.0'];

$supportsPfa = array_filter(
    $versions,
    version_compare(?, '8.6', '>='),
);
```

### `\Time\Duration` e `clamp()`

```php
use Time\Duration;

function backoff(
    Duration $baseDelay,
    Duration $step,
    int $attempt,
): void {
    $delay = $baseDelay->add($step->multiplyBy(2 ** $attempt));

    // Durations são comparáveis, então min() funciona diretamente.
    $delay = min($delay, Duration::fromSeconds(30));

    time_nanosleep($delay->seconds, $delay->nanoseconds);
}

// Pré-configura os atrasos usando Partial Function Application.
$waitBeforeRetry = backoff(
    Duration::fromSeconds(1),
    Duration::fromMilliseconds(100),
    attempt: ?,
);
$waitBeforeRetry($attempt);
```

```php
var_dump(clamp(-10, 0, 100));
// int(0)

var_dump(clamp(110, 0, 100));
// int(100)
```

### Enum `SortDirection`

```php
public function orderBy(
    string $column,
    SortDirection $direction = SortDirection::Ascending,
): static {
    $this->orderBy[] = $column . ' ' . match ($direction) {
        SortDirection::Ascending => 'ASC',
        SortDirection::Descending => 'DESC',
    };

    return $this;
}
```

### Valores padrão em propriedades readonly

```php
final readonly class SlugRule implements Rule
{
    public string $parser = SlugParser::class;
}
```

### Erros de stream como exceções

```php
$context = stream_context_create([
    'stream' => [
        'error_mode' => StreamErrorMode::Exception,
    ],
]);

try {
    $config = file_get_contents('/etc/app/config.json', context: $context);
} catch (StreamException $e) {
    foreach ($e->getErrors() as $error) {
        // $error->code é um caso do enum StreamErrorCode
        log_error($error->code->name, $error->message);
    }
}
```

### Depreciações e quebras de compatibilidade

Algumas mudanças que merecem atenção na hora de atualizar:

- `return` dentro de `finally` foi depreciado.
- `is_double()`, `is_long()`, `is_integer()` e `doubleval()` foram depreciadas.
- Funções de regex do mbstring (`mb_ereg`, `mb_split` etc.) foram depreciadas.
- `spl_object_hash()` foi depreciada.
- `let` e `is` como nomes de classes, funções ou constantes foram depreciados.
- Sessões agora têm `session.use_strict_mode` e `session.cookie_httponly` ativados e `session.cookie_samesite=Lax` por padrão.
- `trim()`, `ltrim()` e `rtrim()` passam a remover `\f` por padrão.
