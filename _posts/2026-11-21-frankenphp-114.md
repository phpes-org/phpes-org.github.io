Dois dias após o [lançamento do PHP 8.6]({% post_url 2026-11-20-php-86-lancado %}), o [FrankenPHP](https://frankenphp.dev/) 1.14 chegou tornando o PHP 8.6 a versão padrão.

Para quem ainda não conhece, FrankenPHP é um servidor de aplicação PHP construído em cima do servidor web Caddy, e desde 2025 faz parte da organização oficial do PHP no GitHub.

### PHP 8.6 por padrão

- **Docker**: as tags `latest` e as tags só com versão (`1.14`, `1`) agora apontam para imagens com PHP 8.6. Versões anteriores continuam disponíveis pelas tags `php8.x`, por exemplo `dunglas/frankenphp:1.14-php8.5`.
- **Binários estáticos**: compilados com PHP 8.6. Algumas extensões ainda não têm versão compatível (amqp, apcu, igbinary, imagick, lz4, memcached, msgpack, redis, xlswriter), então são compiladas a partir de branches de desenvolvimento ou pull requests.
- **Windows**: binários do PHP 8.6 compilados com Visual Studio 2026.

### Atenção ao atualizar

As imagens Docker com PHP 8.6 não incluem mais o mbstring nem o PECL. Instale as extensões necessárias com `install-php-extensions`:

```dockerfile
FROM dunglas/frankenphp:1.14

RUN install-php-extensions mbstring
```

Quem quiser continuar no PHP 8.5 pode usar as tags `php8.5`.

### `file_server` configurável no `php_server`

A diretiva `php_server` agora aceita um bloco `file_server` com qualquer opção do `file_server` do Caddy, exceto `root`:

```nginx
php_server {
	file_server {
		precompressed zstd br gzip
	}
}
```
